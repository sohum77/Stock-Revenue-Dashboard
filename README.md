# Stock Data Extraction & Visualization

IBM Data Analyst Professional Certificate:- Capstone Assignment

Extracted historical stock price and revenue data for Tesla and GameStop using yfinance and web scraping (BeautifulSoup). Visualised historical share price vs quarterly revenue using Plotly dashboards.

## Tech Stack
Python · yfinance · BeautifulSoup · Pandas · Plotly

## Skills Demonstrated
- REST API data extraction
- Web scraping
- Financial data visualisation
- Plotly dashboard creation
